# Lecture Starter Code

Today's lecture begins with a pre-built starter application. Rather than building the project from scratch, we'll use this existing codebase to focus on **Docker Compose**, **Nginx**, **Gunicorn**, and the overall **full-stack application architecture**.

The repository for this lecture originally contained the starter code. During the lecture, however, we replace portions of that code as we build out the application. As a result, the repository's latest commit no longer matches the starting point used in class.
