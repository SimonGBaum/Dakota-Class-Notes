# Week 1 — The Foundation

## Day 2

**Date:** June 2, 2026

**Title:** Git & Github — Version Control Is Non-Negotiable

---

Day 2 was all about Git and GitHub — the backbone of collaborative software development.

We covered the core concepts: repositories, commits, branches, merges, and pull requests. Git is one of those tools that looks simple on the surface but has real depth once you start working with teams and real codebases. Understanding the mental model — that Git tracks *changes*, not files — made a lot of things click.

GitHub added the social layer: forking repos, opening PRs, and understanding how open source collaboration actually works in practice.

The most important thing I walked away with: **commit often, write meaningful messages, and branch early**. A good Git workflow isn't just about saving your work — it's about communicating your intent to everyone else on the project (including future you).
