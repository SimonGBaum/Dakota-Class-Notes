# Week 1 — The Foundation

## Day 4

**Date:** June 4, 2026

**Title:** The Agent Loop — How Claude Code Actually Works

---

Day 4 was one of the more mind-expanding days so far. We went under the hood to understand the *agent loop* — the cycle that powers tools like Claude Code.

At its core, an AI coding agent doesn't just respond to a single prompt. It operates in a loop: it reads context, decides on an action (like reading a file, running a command, or writing code), observes the result, and then decides what to do next. That loop repeats until the task is complete or it hits a dead end.

Understanding this changed how I think about interacting with these tools. When I give Claude Code a task, it's not executing one instruction — it's navigating a decision tree, using tools, and course-correcting in real time. That means the way I frame tasks, provide context, and set expectations actually matters a lot.

We also installed Claude Code itself and ran our first sessions. Seeing the loop play out in real time made the theory concrete.

The takeaway: **an agent is only as good as the context it has**. Your job as the human is to give it the right information and boundaries.
