# Week 1 — The Foundation

## Day 1

**Date:** June 1, 2026

**Title:** Machine Setup — Getting the Tools in Place

---

Before you can write a single line of code, you have to make sure your machine is ready to run it. That was Day 1 in a nutshell.

We went through the full setup: installing the right versions of Python, Node, Git, and a handful of other tools that I'll be relying on throughout the program. We also configured our terminals, set up our editors, and made sure everything could actually talk to each other.

It sounds unglamorous, but there's something satisfying about getting a clean machine into a state where it's ready to do real work. Every tool installed felt like one less obstacle between me and actually building something.

The biggest takeaway: **environments matter**. The reason we set things up carefully is so that "it works on my machine" never becomes an excuse. A consistent, well-configured environment is the foundation everything else sits on.
