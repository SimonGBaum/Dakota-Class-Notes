# Week 1 — The Foundation

## Day 5

**Date:** June 5, 2026

**Title:** Handling Context & MCP Servers — Extending the Agent

---

The final day of week one tied everything together by going deeper on two related ideas: context management and MCP (Model Context Protocol) servers.

Context management is the practice of being intentional about what information you give an AI agent and when. Agents have a finite context window — they can only "see" so much at once. If you dump everything in, you get noise. If you're too sparse, the agent lacks what it needs. Learning to curate context is a skill, and one that directly affects the quality of what you get back.

MCP servers were the new concept of the day. They're a standardized way to connect external tools and data sources to an AI agent — essentially giving the agent new capabilities beyond its defaults. Think of it as a plugin system: you can wire up a database, a file system, an API, or any other resource, and the agent can call into it as part of its loop.

Together, context management and MCP servers are about **giving the agent the right tools and information at the right time** — which is really just good engineering practice applied to a new kind of system.
